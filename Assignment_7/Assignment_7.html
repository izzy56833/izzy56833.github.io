Problem 4:

We can find the line of best fit using cor, sd, and the mean to find the b0 and b1 in b0 + b1x. The equation for b1 = r * sy / sx and b0 = mean(y) - mean(x) * b1.

For this problem Temp is our Y and Chirps is our x.

df <- data.frame(
temp = c(79, 74, 73, 76, 82, 72, 71, 79, 83, 70, 73, 75, 77),
chirps = c(44, 40, 38, 43, 48, 37, 34, 45, 51, 32, 35, 42, 43)
)
#I will now find the sds, means, and corr.
cor <- cor(df$temp,df$chirps, use = "pairwise.complete.obs")
cor
[1] 0.970876
sdtemp <- sd(df$temp) 
sdchirps <- sd(df$chirps)
mtemp <- mean(df$temp)
mchirps <- mean(df$chirps)

b1 = cor * (sdtemp / sdchirps)
b0 = mtemp - b1*mchirps
b1
[1] 0.7139926
b0
[1] 46.47353

We can see that b1 = 0.714 and b0 = 46.47. This means that the intercept is 46.47 and the slope is 0.714. This is the same slope and intercept that the line of best fit gave us.
